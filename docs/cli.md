# DINAH command-line utility (initial scaffold)

Build or install the crate using the normal Cargo workflow, then invoke `dinah`.

```text
dinah --help
dinah --version
dinah init [PATH]
dinah run [PATH]
```

`PATH` defaults to the current working directory. `dinah init` creates `DINAH.toml` with a starter `[project]` section and refuses to overwrite an existing manifest. `dinah run` reads the manifest and validates a non-empty quoted `project.name`, then reports the project it found. **It does not execute user tasks yet**; task files, command execution, richer TOML parsing, structured output and friendly error taxonomy remain future CLI work.

The initial parser deliberately supports only the small manifest shape generated by `dinah init`. It is not a general TOML parser.
